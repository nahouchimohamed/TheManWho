# The Man Who — Playable Prototype

A short Godot 4 vertical slice: Hollow Knight–like atmosphere, Sekiro-lite deflect combat, and a cinematic ending that renames the game.

## Requirements

- **Godot 4.3+** (Standard / non-.NET)

## How to play (easiest)

Run the Windows build:

`build/TheManWho.exe`

Keep the project folder together (the exe expects assets next to `build/`).

### Or from the Godot editor

1. Open Godot 4.3
2. Import `project.godot`
3. Press **F5**

### Controls

- **A / D** — move
- **Space** — jump
- **LMB** — swing
- **RMB** — parry (time it as the enemy telegraphs)
- **E** — deathblow (when posture is broken)

After the duel, the ally dies → credits rename the game to **The Man Who Lost It All**.

## Prototype scope

One path level (shades + Ashen Blade boss), one ending (`lost_it_all`). Built to test combat feel and the title-morph credits idea.
